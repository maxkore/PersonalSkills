## Using a skill

Copy the skill's folder into your coding assistant's skills directory. Read its README for installation requirements, examples, and configuration. Each `SKILL.md` contains the instructions the assistant uses.

## Adding a skill

Give each skill its own folder with a `SKILL.md` and a `README.md`. Keep helper scripts and tests alongside it when needed, then add a row to the skills table above.

Keep personal profiles, session history, credentials, and runtime data outside this public repository.
